
# Smart College FAQ Chatbot

## Overview

Smart College FAQ Chatbot is a Python-based chatbot that helps students find answers to questions about their college syllabus. It uses a locally running Large Language Model (LLM) through Ollama to generate answers based on selected course materials.

Students can select their branch, academic year, cycle or semester, and course. They can then ask questions related to the selected syllabus and receive answers from the chatbot.

The project supports AIML and CSE branches and provides both a Streamlit web interface and a command-line interface.

## Objectives

- Provide an interactive chatbot for syllabus-related queries.
- Help students access course information easily.
- Generate answers using a locally running language model.
- Organize syllabus content by branch, year, semester, and course.
- Restrict answers to the selected syllabus content.

## Technologies Used

- **Programming Language:** Python
- **Web Interface:** Streamlit
- **Language Model Runtime:** Ollama
- **LLM:** Phi-3
- **Libraries:** os, streamlit, ollama

## Features

- Supports AIML and CSE branches.
- Provides syllabus selection by academic year.
- Supports physics and chemistry cycles for the first year.
- Supports semester selection for second, third, and fourth years.
- Loads course content from text files.
- Answers questions based on the selected syllabus.
- Displays a fallback response when information is not mentioned in the supplied syllabus.
- Provides both web-based and command-line interfaces.

## How It Works

1. **Select Branch:** Choose AIML or CSE.
2. **Select Academic Year:** Choose the required year.
3. **Select Cycle or Semester:** Select the appropriate cycle for the first year or semester for later years.
4. **Select Course:** Choose a course from the available syllabus files.
5. **Enter a Question:** Ask a question related to the selected course.
6. **Generate an Answer:** The chatbot sends the question and a portion of the syllabus to the Phi-3 model through Ollama.
7. **Display the Response:** The model generates an answer using the supplied syllabus context.

If the required information is not present in the provided context, the prompt instructs the model to respond with "Not mentioned in syllabus."

## Installation and Setup

### Prerequisites

- Python 3.9 or a compatible Python version.
- Ollama installed on your system.
- The Phi-3 model downloaded through Ollama.

### Step 1: Clone the Repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd faq-chatbot-main
```

Replace `<YOUR_GITHUB_REPOSITORY_URL>` with your actual repository URL.

### Step 2: Install Dependencies

```bash
pip install streamlit ollama
```

### Step 3: Install the Phi-3 Model

```bash
ollama pull phi3
```

### Step 4: Start Ollama

Ensure the Ollama service is running on your computer.

### Step 5: Run the Streamlit Application

```bash
streamlit run app.py
```

The application will display a local URL in the terminal. Open it in your browser to use the chatbot.

### Step 6: Run the Command-Line Version

To use the terminal-based chatbot instead, run:

```bash
python chatbot.py
```

Follow the prompts to select the branch, year, cycle or semester, and course. Enter questions about the selected syllabus. Type `exit` to stop the command-line chatbot.

## Limitations

- Answers depend on the syllabus content available in the text files.
- The application currently passes only the first 2,000 characters of the selected syllabus to the model.
- Ollama must be running locally, and the Phi-3 model must be available.
- Responses may contain inaccuracies because they are generated by a language model.
- The chatbot does not currently use a vector database or a retrieval-augmented generation pipeline.
